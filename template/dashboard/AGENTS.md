# For agents

This is a dashboard app. Before changing anything, read, in order:
https://github.com/Cooperation-org/baobab/blob/main/PRINCIPLES.md,
https://github.com/Cooperation-org/baobab/blob/main/AGENTS.md,
https://github.com/Cooperation-org/baobab/blob/main/CONTRACT.md.

The dashboard app's tables are the ones in `dashboard/models.py`. Adding another needs the project
owner's OK. Pages here load no inline script: the Content-Security-Policy allows this
dashboard app and its peers' cards files only.

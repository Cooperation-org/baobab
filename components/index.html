Baobab components

Cards you can drop into any page: one script tag and one element. Each one below is running live.

lt-claims atproto-thread atproto-feed linked-badge

<lt-claims>

Recent LinkedTrust claims, filtered, checked again every minute.

data-up
The LinkedTrust server
data-query
Text to match
data-filter
ratings or credentials
data-subject
Claims about exactly this URL
data-claim
Claim type, e.g. ENDORSES
data-issuer
Who made the claim
data-limit
How many (10)
data-refresh
Seconds between checks (60; 0 = never)
<script src="https://demos.linkedtrust.us/baobab/components/lt-claims.js" defer></script>
<lt-claims data-up="https://live.linkedtrust.us"
           data-filter="ratings" data-limit="4"></lt-claims>

Live: ratings

<atproto-thread>

Comments on your page, made by replying to a Bluesky post. Replies show here within a minute. Nothing is stored anywhere but Bluesky.

data-up
An AT Proto app view
data-post
The post: a bsky.app link or an at:// URI
data-depth
Reply levels (3)
data-refresh
Seconds between checks (60)
<script src="https://demos.linkedtrust.us/baobab/components/atproto-thread.js" defer></script>
<atproto-thread data-up="https://public.api.bsky.app"
  data-post="at://did:plc:xztctnvt5ycnsippd3orwqk7/app.bsky.feed.post/3mhysbqcas62w"></atproto-thread>

Live: replies to a linkedclaims.com post

<atproto-feed>

The latest posts from one Bluesky account.

data-up
An AT Proto app view
data-actor
Handle or DID
data-limit
How many (5)
data-replies
yes to include replies
data-refresh
Seconds between checks (120)
<script src="https://demos.linkedtrust.us/baobab/components/atproto-feed.js" defer></script>
<atproto-feed data-up="https://public.api.bsky.app"
              data-actor="linkedtrust.us" data-limit="3"></atproto-feed>

Live: linkedtrust.us

<linked-badge>

One verified claim as a badge. Used for testimonials on linkedtrust.us. Older style: its own shadow DOM, and a host attribute instead of data-up.

claim-id
The claim
layout
Badge layout
theme
Colors
api-base
The LinkedTrust server
<script src="https://live.linkedtrust.us/badge.js" defer></script>
<linked-badge claim-id="124448"></linked-badge>
